# Обследование ЛЭП в Gazebo

Задача A «Почти как на финале», НТО 26/27. [Условие](https://new.contest.yandex.ru/contests/100384/problems?id=420131%2F2026_11_03%2FBtB4sgtoFW)

## Запуск на Ubuntu 24.04

`setup.sh` ставит ROS 2 Jazzy, Gazebo Harmonic и OpenCV. Установка нужна один раз.

```bash
git clone https://github.com/godplayTty/nto-lep-gazebo.git lep-inspection
cd lep-inspection
./setup.sh
./run.sh --seed 20261112
```

С этим seed опоры встанут так же, как на записи. Без `--seed` скрипт выберет новый мир и напечатает его номер. Для прогона без окна Gazebo, в том числе из Dev Container, добавьте `--headless` перед `--seed`. [Видео прогона](docs/mission.mp4)

В браузере откройте панель на порту 8080. Если браузер на хосте, а Gazebo в виртуальной машине или контейнере, пробросьте этот порт. [Панель](http://127.0.0.1:8080)

| Кнопка | Что произойдёт |
| --- | --- |
| **Старт** | В терминале появится `Запуск mission.py`. Дрон взлетит, когда будут готовы камеры. |
| **Стоп** | Дрон сядет в текущей точке. |
| **Kill switch** | Роторы сразу отключатся. |

После **Стоп** или **Kill switch** для следующего полёта заново запустите `./run.sh`.

## Как нумеруются изоляторы

Камера снизу видит 234 маркера ArUco. Генератор пишет их координаты в `generated/aruco_map.json`, по этой карте дрон определяет своё положение. Фронтальная камера ищет синюю табличку и по ней вычисляет центр опоры. Номер изолятора привязан к передней стороне. Например, №1 при осмотре сзади будет слева в кадре.

| Траверса | Слева спереди | Справа спереди |
| --- | --- | --- |
| 1,2 м | 2 | 1 |
| 0,9 м | 3 | 4 |

В пролёте провод соединяет изоляторы с одним номером. Чёрный означает «исправен», коричневый — «износ», красный — «дефект». После осмотра дрон проходит над третьей опорой и садится на старте.

## Результаты прогона

Панель получает координаты и цвета из `/insulators`. Она берёт из `generated/reference.json` только схему проводов. Координаты для сверки из этого файла читает `evaluate.py` после полёта.

| Данные | Топик или система координат |
| --- | --- |
| Нижняя камера | `/camera/down/image`, `/camera/down/camera_info` |
| Передняя камера | `/camera/front/image`, `/camera/front/camera_info` |
| TF | `aruco_map → base_link → down_optical, front_optical` |
| Результат осмотра | `/insulators`, JSON в поле `data` сообщения `std_msgs/msg/String` |

Строка из прогона `20261112` для верхнего правого изолятора первой опоры. Пара `tower_id` и `number` определяет запись.

```json
{"tower_id":"T01","x":2.8875440813852578,"y":-0.04586809146113749,"number":1,"color":"brown","state":"Износ"}
```

```bash
source /opt/ros/jazzy/setup.bash
export ROS_AUTOMATIC_DISCOVERY_RANGE=LOCALHOST
ros2 topic echo /insulators --qos-durability transient_local
```

После посадки можно сравнить результаты с эталоном. Допуск по центру — 20 см.

```bash
curl -fsS http://127.0.0.1:8080/state |
  python3 -c 'import json,sys; print(json.dumps(json.load(sys.stdin)["results"]))' > /tmp/lep-results.json
python3 evaluate.py generated/reference.json /tmp/lep-results.json
```

Для `20261112` и `7287` получилось `Опоры 3/3, изоляторы 12/12`, максимальная ошибка центра — около 1 см. **Стоп** и **Kill switch** проверены отдельными прогонами. Чтобы записать свой полёт, включите **Follow** у `inspection_quad` в Gazebo и оставьте в кадре панель и терминал.
